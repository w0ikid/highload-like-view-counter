# Highload Counters

Учебный сервис постов, лайков и просмотров с пользовательскими аккаунтами.

## Пользователи

**User**: Зарегистрированный пользователь с уникальным email и отображаемым именем.

**Credential**: Секрет для входа пользователя по паролю, отдельный от его профиля.

**Session**: Один вход пользователя, который можно продлевать или завершить независимо от других входов.

**PasswordReset**: Одноразовое разрешение установить новый пароль после обращения к почтовому ящику пользователя.

## Счётчики

**Post**: Тестовая публикация, для которой учитываются лайки и просмотры.

**Like**: Текущее положительное отношение пользователя к посту; у пары пользователь–пост может быть только один лайк.

**ViewEvent**: Сообщение о просмотре поста определённым зрителем. Повторы в пределах окна после первого принятого просмотра не увеличивают счётчик.

**Viewer**: Зритель, идентификатор которого используется для дедупликации просмотров; не обязательно зарегистрированный пользователь.

**PostCounter**: Сохранённые количества лайков и просмотров поста.

**FlushBatch**: Именованная пачка накопленных изменений просмотров, которую можно безопасно повторить при восстановлении.
