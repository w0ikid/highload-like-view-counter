Общий service для REST и gRPC. Проверяет пользователя, положительные ID, размеры и уникальность запросов. До записи views проверяет все post_id одним SQL-запросом. Разделяет общий deadline транспорта и бюджеты зависимостей: истечение бюджета Redis/PostgreSQL — 503/UNAVAILABLE, общего запроса — 504/DEADLINE_EXCEEDED.
