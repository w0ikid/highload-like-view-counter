Один отдельный worker-процесс: flush каждую секунду и reconciliation каждую минуту. API фоновые задачи не запускает. Выделенное PostgreSQL-соединение держит advisory lock 743270021; второй worker завершается. Потеря lock-соединения завершает worker, Compose перезапускает его. Все задачи имеют deadline. После восстановления Redis/PostgreSQL сохраняемый in-flight batch повторяется автоматически. Ручной reconciler: go run ./cmd/reconcile.
