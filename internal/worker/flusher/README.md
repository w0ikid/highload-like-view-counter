Реализация находится в internal/worker/worker.go, Redis Views и PostgreSQL counter.Repository. Claim Lua переносит pending в in-flight через RENAME и сохраняет UUID. Новые события создают новый pending. ApplyBatch вставляет UUID в counter_flush_log и обновляет views в одной транзакции. Ack удаляет только in-flight с совпадающим UUID и только после commit. Аварийные завершения до commit и после commit до Ack проверены отдельными subprocess-тестами.
